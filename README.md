# 👻 Ghost सुरक्षा मॉड्यूल
**PowerShell आधारित Windows अर Azure सुरक्षा मजबूती औजार**

> **Windows अंतिम बिंदु अर Azure माहौल खातर सक्रिय सुरक्षा मजबूती।** Ghost अनावश्यक सेवावां अर प्रोटोकॉल नै बंद करण सूं आम हमलो री वेक्टर नै घटावण में मदद करण वाळा PowerShell आधारित मजबूती फंक्शन देवै।

## ⚠️ महत्वपूर्ण जिम्मेदारी अस्वीकरण

**परीक्षण जरूरी है**: Ghost नै हमेशा पैली गैर-उत्पादन माहौल में टेस्ट करो। सेवावां बंद करणो वैध व्यापारिक काम नै प्रभावित कर सकै।

**कोई गारंटी कोनी**: भलांई Ghost आम हमलो री वेक्टर नै निशाना बणावै, कोई सुरक्षा औजार सगळा हमलां नै रोक कोनी सकै। यो एक व्यापक सुरक्षा रणनीति रो एक घटक है।

**परिचालन प्रभाव**: कीं फंक्शन सिस्टम कार्यक्षमता नै प्रभावित कर सकै। तैनाती सूं पैली हरेक सेटिंग नै ध्यान सूं देखो।

**पेशेवर मूल्यांकन**: उत्पादन माहौल खातर, सुरक्षा विशेषज्ञां सूं सलाह लो जिसूं यो सुनिश्चित होय सकै कि सेटिंग्स थारै संगठन री जरूरत सूं मेळ खावै।

## 📊 सुरक्षा लैंडस्केप

Ransomware रो नुकसान **2025 में $57 बिलियन** तक पूग ग्यो, अनुसंधान दिखावै कि घणा सफल हमला बुनियादी Windows सेवावां अर गलत कॉन्फ़िगरेशन रो फायदो उठावै। आम हमलो री वेक्टर में शामिल है:

- **90% ransomware घटनावां** में RDP दुरुपयोग शामिल है
- **SMBv1 कमजोरी** WannaCry अर NotPetya जैड़ा हमलां नै सक्षम बणाया
- **दस्तावेज मैक्रो** प्राथमिक मैलवेयर डिलीवरी तरीको बण्यो रह्यो है
- **USB आधारित हमला** एयर-गैप्ड नेटवर्क नै लक्षित करतो रह्यो है
- **PowerShell दुरुपयोग** हाल रा साल में घणो बढ्यो है

## 🛡️ Ghost सुरक्षा फंक्शन

Ghost **16 Windows मजबूती फंक्शन** प्लस **Azure सुरक्षा एकीकरण** देवै:

### Windows एंडपॉइंट मजबूती

| फंक्शन | उद्देश्य | विचार |
|----------|---------|----------------|
| `Set-RDP` | Remote Desktop पहुंच रो प्रबंधन करै | दूरस्थ प्रशासन नै प्रभावित कर सकै |
| `Set-SMBv1` | पुराणो SMB प्रोटोकॉल नै नियंत्रण करै | घणा पुराणा सिस्टम खातर जरूरी |
| `Set-AutoRun` | AutoPlay/AutoRun नै नियंत्रण करै | उपयोगकर्ता सुविधा नै प्रभावित कर सकै |
| `Set-USBStorage` | USB स्टोरेज डिवाइस नै सीमित करै | वैध USB इस्तेमाल नै प्रभावित कर सकै |
| `Set-Macros` | Office मैक्रो निष्पादन नै नियंत्रण करै | मैक्रो-सक्षम दस्तावेज नै प्रभावित कर सकै |
| `Set-PSRemoting` | PowerShell रिमोटिंग रो प्रबंधन करै | दूरस्थ प्रबंधन नै प्रभावित कर सकै |
| `Set-WinRM` | Windows Remote Management नै नियंत्रण करै | दूरस्थ प्रशासन नै प्रभावित कर सकै |
| `Set-LLMNR` | नाम रिज़ॉल्यूशन प्रोटोकॉल रो प्रबंधन करै | आम तौर पर अक्षम करणो सुरक्षित है |
| `Set-NetBIOS` | TCP/IP पर NetBIOS नै नियंत्रण करै | पुराणा एप्लिकेशन नै प्रभावित कर सकै |
| `Set-AdminShares` | प्रशासनिक शेयर रो प्रबंधन करै | दूरस्थ फ़ाइल पहुंच नै प्रभावित कर सकै |
| `Set-Telemetry` | डेटा संग्रह नै नियंत्रण करै | निदान क्षमता नै प्रभावित कर सकै |
| `Set-GuestAccount` | गेस्ट खातो रो प्रबंधन करै | आम तौर पर अक्षम करणो सुरक्षित है |
| `Set-ICMP` | ping प्रतिक्रिया नै नियंत्रण करै | नेटवर्क निदान नै प्रभावित कर सकै |
| `Set-RemoteAssistance` | Remote Assistance रो प्रबंधन करै | helpdesk संचालन नै प्रभावित कर सकै |
| `Set-NetworkDiscovery` | नेटवर्क खोज नै नियंत्रण करै | नेटवर्क ब्राउज़िंग नै प्रभावित कर सकै |
| `Set-Firewall` | Windows Firewall रो प्रबंधन करै | नेटवर्क सुरक्षा खातर महत्वपूर्ण |

### Azure क्लाउड सुरक्षा

| फंक्शन | उद्देश्य | आवश्यकता |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | बुनियादी Azure AD सुरक्षा नै सक्षम करै | Microsoft Graph अनुमति |
| `Set-AzureConditionalAccess` | पहुंच नीति नै कॉन्फ़िगर करै | Azure AD P1/P2 लाइसेंसिंग |
| `Set-AzurePrivilegedUsers` | विशेषाधिकार खातो रो ऑडिट करै | Global Admin अनुमति |

### एंटरप्राइज़ तैनाती विकल्प

## 🔍 फंक्शन विवरण

### मुख्य मजबूती फंक्शन

#### नेटवर्क सेवा
- **RDP**: रिमोट डेस्कटॉप पहुंच नै ब्लॉक करै या पोर्ट नै रैंडमाइज़ करै
- **SMBv1**: पुराणो फ़ाइल शेयरिंग प्रोटोकॉल नै निष्क्रिय करै
- **ICMP**: जासूसी खातर ping प्रतिक्रिया नै रोकै
- **LLMNR/NetBIOS**: पुराणा नाम रिज़ॉल्यूशन प्रोटोकॉल नै ब्लॉक करै

#### एप्लिकेशन सुरक्षा
- **मैक्रो**: Office एप्लिकेशन में मैक्रो निष्पादन नै निष्क्रिय करै
- **AutoRun**: हटावण जोग्यो मीडिया सूं स्वचालित निष्पादन नै रोकै

#### दूरस्थ प्रबंधन
- **PSRemoting**: PowerShell दूरस्थ सत्र नै निष्क्रिय करै
- **WinRM**: Windows Remote Management नै बंद करै
- **Remote Assistance**: दूरस्थ सहायता कनेक्शन नै ब्लॉक करै

#### पहुंच नियंत्रण
- **Admin Shares**: C$, ADMIN$ शेयर नै निष्क्रिय करै
- **Guest Account**: गेस्ट खातो पहुंच नै निष्क्रिय करै
- **USB Storage**: USB डिवाइस उपयोग नै सीमित करै

### Azure एकीकरण
```powershell
# Azure टेनेंट सूं जुड़ो
Connect-AzureGhost -Interactive

# सुरक्षा डिफ़ॉल्ट नै सक्षम करो
Set-AzureSecurityDefaults -Enable

# सशर्त पहुंच कॉन्फ़िगर करो
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# विशेषाधिकार उपयोगकर्ता रो ऑडिट करो
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune एकीकरण (v2 में नवो)
```powershell
# Intune सूं जुड़ो
Connect-IntuneGhost -Interactive

# Intune नीति रै माध्यम सूं तैनात करो
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ महत्वपूर्ण विचार

### परीक्षण आवश्यकता
- **लैब माहौल**: पैली अलग माहौल में सगळी सेटिंग रो टेस्ट करो
- **चरणबद्ध तैनाती**: समस्या पिछाणण खातर धीरे-धीरे फैलावो
- **रोलबैक योजना**: सुनिश्चित करो कि जरूरत पड़्यां बदळाव नै वापस कर सको
- **दस्तावेज़ीकरण**: रिकॉर्ड करो कि थारै माहौल खातर कुण सी सेटिंग काम करै

### संभावित प्रभाव
- **उपयोगकर्ता उत्पादकता**: कीं सेटिंग दैनिक वर्कफ़्लो नै प्रभावित कर सकै
- **पुराणा एप्लिकेशन**: पुराणा सिस्टम नै कीं विशिष्ट प्रोटोकॉल री जरूरत होय सकै
- **दूरस्थ पहुंच**: वैध दूरस्थ प्रशासन पर प्रभाव रो विचार करो
- **व्यापारिक प्रक्रिया**: सत्यापित करो कि सेटिंग महत्वपूर्ण फंक्शन नै नुकसान नीं पूगावै

### सुरक्षा सीमा
- **गैरी रक्षा**: Ghost सुरक्षा रो एक परत है, पूरो समाधान कोनी
- **चालू प्रबंधन**: सुरक्षा नै निरंतर निगरानी अर अपडेट री जरूरत होवै
- **उपयोगकर्ता प्रशिक्षण**: तकनीकी नियंत्रण नै सुरक्षा जागरूकता सूं जोड़णो चाइजै
- **खतरो विकास**: नवा हमलो रा तरीका मौजूदा सुरक्षा नै बायपास कर सकै

## 🎯 हमलो परिदृश्य उदाहरण

भलांई Ghost आम हमलो री वेक्टर नै लक्षित करै, विशिष्ट रोकथाम उचित कार्यान्वयन अर परीक्षण पर निर्भर करै:

### WannaCry-शैली हमला
- **न्यूनीकरण**: `Set-Ghost -SMBv1` कमजोर प्रोटोकॉल नै निष्क्रिय करै
- **विचार**: सुनिश्चित करो कि कोई पुराणो सिस्टम SMBv1 री जरूरत कोनी

### RDP-आधारित Ransomware
- **न्यूनीकरण**: `Set-Ghost -RDP` रिमोट डेस्कटॉप पहुंच नै ब्लॉक करै
- **विचार**: वैकल्पिक दूरस्थ पहुंच तरीको री जरूरत होय सकै

### दस्तावेज़-आधारित मैलवेयर
- **न्यूनीकरण**: `Set-Ghost -Macros` मैक्रो निष्पादन नै निष्क्रिय करै
- **विचार**: वैध मैक्रो-सक्षम दस्तावेज नै प्रभावित कर सकै

### USB-वितरित खतरो
- **न्यूनीकरण**: `Set-Ghost -USBStorage -AutoRun` USB कार्यक्षमता नै सीमित करै
- **विचार**: वैध USB डिवाइस उपयोग नै प्रभावित कर सकै

## 📚 सर्वोत्तम अभ्यास

### तैनाती सूं पैली
1. **वर्तमान स्थिति दस्तावेज**: बदळाव सूं पैली `Get-Ghost` चलावो
2. **पूरी तरै परीक्षा**: गैर-उत्पादन माहौल में मान्य करो
3. **रोलबैक योजना**: हरेक सेटिंग नै कियां वापस करणो है जाणो
4. **हितधारक समीक्षा**: सुनिश्चित करो कि व्यापारिक इकाई बदळाव रो अनुमोदन करै

### तैनाती रै दौरान
1. **चरणबद्ध दृष्टिकोण**: पैली पायलट समूह में तैनात करो
2. **प्रभाव निगरानी**: उपयोगकर्ता शिकायत या सिस्टम समस्या देखो
3. **समस्या दस्तावेज**: भविष्य रै संदर्भ खातर कोई समस्या रिकॉर्ड करो
4. **बदळाव संचार**: उपयोगकर्ता नै सुरक्षा सुधार रै बारै में बतावो

### तैनाती रै बाद
1. **नियमित मूल्यांकन**: सेटिंग सत्यापित करण खातर समय-समय पर `Get-Ghost` चलावो
2. **दस्तावेज़ीकरण अपडेट**: सुरक्षा कॉन्फ़िगरेशन नै वर्तमान राखो
3. **प्रभावशीलता समीक्षा**: सुरक्षा घटना री निगरानी करो
